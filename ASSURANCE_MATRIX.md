# Sanctuary Assurance Matrix

This matrix is the authoritative source for Sanctuary trust claims. Product, release, and marketing copy must trace each trust claim to a `proven` or `partial` row here, and must preserve the platform, gap, and next-proof limits named in that row. As of main at PR #276, the trust-path claims for tamper-evident audit chain, state envelope integrity, and durable critical audit are mechanically true on main.

Status enum: `proven`, `partial`, `manual`, `not_implemented`, `planned`, `in_flight`, `unknown`.
