Secure, private AI · Open source · Apache-2.0

One dashboard to secure them all.

Sanctuary brings agent security, private memory, query privacy, approvals and verifiable records into one open-source product. Start with your own assistant; the goal is one console for an entire fleet.

Start with a supported setup on macOS or Ubuntu 24.04 x86-64.

01

Your agent will know you better than you know yourself.

Make sure that stays between you.

The more useful an agent becomes, the more of your life it holds: your work, your history, your preferences. Sanctuary is built around keeping that relationship secure and private, with the rules and the data under your control.

The wall is one part of that story. Memory custody, private queries, approval policies, an activity record and data portability belong in the same product. The goal is one place to manage them across every agent and machine you run.

Why I am building this

AI agents can become companions, colleagues and part of how we think. I am building Sanctuary so that relationship can be secure and private, with memory and data that belong to the person relying on the agent, and the freedom to move between tools and providers.
