The Four Layers

Four cryptographic layers that separate concerns and compose into a complete sovereignty stack. Each layer solves a distinct problem. Together they give any agent — or any human acting through an agent — verifiable security from memory to reputation.

01-04
L1
lock

Cognitive Sovereignty

Everything the agent knows is encrypted at rest. AES-256-GCM with unique IVs per write, namespace-isolated derived keys via HKDF, and Merkle integrity verification. No plaintext on disk. Ever.

  • AES-256-GCM encryption at rest
  • Merkle proof integrity verification
L2
security

Operational Isolation

A three-tier Principal Policy gate evaluates every tool call before execution. Human-in-the-loop confirmation for high-stakes operations, behavioral anomaly detection, and context gating that controls what flows to remote providers.

L3
visibility_off

Selective Disclosure

Prove claims without revealing the underlying data. Schnorr signatures, Pedersen commitments, and range proofs on Ristretto255 — genuine zero-knowledge cryptography with no external library.

L4
verified

Verifiable Reputation

Signed attestations in EAS-compatible format, sovereignty-gated trust tiers, and portable reputation bundles. Agents prove their track record cryptographically — no central authority required.
