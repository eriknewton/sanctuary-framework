The Four Layers of Sanctuary

A vertical sovereignty stack. Each layer isolates a distinct concern — from encrypted memory to portable reputation — so agents and the humans behind them stay in control.

security

Cognitive Sovereignty

All agent state encrypted at rest with AES-256-GCM. Ed25519 self-custodied identity. Your agent's memory and keys belong to you — always.

Operational Isolation

Three-tier approval gate on every tool call. Dangerous operations require human confirmation. Anomaly detection flags unexpected behavior. Full audit trail.

Selective Disclosure

Prove claims without revealing data. Pedersen commitments, Schnorr proofs, and range proofs built on audited cryptographic primitives.

Verifiable Reputation

Signed attestations, sovereignty-gated trust tiers, and portable reputation bundles. Trust is earned, cryptographically verified, and never platform-locked.
